## Deskripsi
Proyek ini merupakan hasil refactoring dan peningkatan antarmuka web portofolio pribadi serta layanan interaktif dari Minggu 2. Pada praktikum Minggu 3 ini, antarmuka diintegrasikan dengan CSS Framework **Bootstrap 5.3** untuk meningkatkan responsivitas, konsistensi visual, dan efisiensi pengembangan tanpa mengabaikan aspek aksesibilitas (WCAG 2.2).

---

## Fitur & Pembaruan Minggu 3
- **Responsive Navbar:** Menggunakan komponen Bootstrap Navbar lengkap dengan tombol *toggler hamburger* untuk tampilan perangkat seluler.
- **Hero & Profile Section:** Tampilan profil modern dengan pemanfaatan Badges Bootstrap untuk status dan daftar keahlian.
- **Grid Portofolio 4 Kolom:** Layout kartu proyek responsif (`row-cols-1 row-cols-md-2 row-cols-lg-4`) yang menyesuaikan otomatis dengan ukuran layar.
- **Modal Dialog Interaktif:** Integrasi komponen Bootstrap Modal untuk menampilkan detail proyek tanpa berpindah halaman.
- **Formulir Layanan Modern:** Penggunaan komponen Floating Labels, Input Groups, dan struktur sistem Grid pada formulir kontak/layanan.
- **Custom Utility Styles:** Penggabungan variabel CSS (`:root`) pada `style.css` untuk kustomisasi tema tanpa merusak aturan framework.
